# SCP: Secret Laboratory — 3D (Rust + Bevy)

Фанатский 3D-прототип по мотивам SCP: Secret Laboratory. Вид от первого лица,
написан на Rust с использованием Bevy 0.15.

## Запуск

Дважды кликните `play_scp_sl_3d.bat` в корне `.arcanic` или выполните:

```
cd scp_sl_3d
cargo run
```

Первое окно — 1040×585 (масштаб 125% на экранах 1536×864), окно можно
растянуть. Шрифт и ассеты подхватываются из папки проекта автоматически
(переменная `BEVY_ASSET_ROOT` выставляется в коде).

Первый запуск собирает проект (Bevy — большой, это занимает время).
Тулчейн: Rust stable `x86_64-pc-windows-gnu` + MinGW GCC (WinLibs).

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | движение |
| Мышь | обзор |
| Shift | бег (тратит выносливость) |
| F | фонарь |
| Esc | пауза / меню |
| Enter | начать |
| R | заново после смерти/побега |

## Что внутри

- Комплекс из семи зон: Зона содержания, Офисы, Лаборатория, КПП, Столовая,
  Реактор, Шлюз — соединены коридорами, стены и потолок в 3D.
- Три карты доступа (уровни 1–3), цветные двери с анимацией открытия.
- **SCP-173**: замирает, пока вы на него смотрите (конус зрения + линия
  видимости); при моргании (каждые 5.5–8 с, 0.22 с) двигается по BFS-пути
  и убивает при контакте. Активируется после подбора карты 1 уровня.
- Фонарь с батареей, спринт с выносливостью, процедурный туман,
  мигающие аварийные лампы, красная пелена опасности.
- HUD: задача, таймер, сектор, карты, полосы, подсказки, экраны меню,
  паузы, смерти и побега. Текст на русском (шрифт `assets/fonts/ui.ttf`).
- Карта, свет и геометрия создаются кодом — внешних ассетов, кроме шрифта, нет.

## Структура

```
scp_sl_3d/
  Cargo.toml
  .cargo/config.toml     # линкер GCC (MinGW)
  assets/fonts/ui.ttf    # шрифт с кириллицей
  src/main.rs            # вся игра
```

## Передать другу

Готовый архив: `releases/scp_sl_3d.zip` (exe + шрифт + `ИГРАТЬ.bat` +
`README_ДРУГУ.md`). Другу достаточно распаковать его на своём ПК и запустить
`ИГРАТЬ.bat` — Rust и Cargo на его машине не нужны. Шрифт ищется рядом с
exe, поэтому папку можно переносить куда угодно.

Собрать заново: `cargo build --release`, затем
`powershell -File tools/make_package.ps1` (положит exe в папку сборки и
соберёт zip в `releases/`).
