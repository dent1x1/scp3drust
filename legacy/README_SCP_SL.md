# SCP: Secret Laboratory — 2D-прототип

Одиночная 2D-игра в духе SCP: Secret Laboratory на Python + pygame.
Вы — сотрудник класса D, выживший после нарушения содержания.
Нужно собрать карты доступа 1–3 уровня и выбраться через шлюз,
не попавшись SCP-173.

## Запуск

```powershell
python scp_sl_game.py
```

Или двойной клик по `play_scp_sl.bat`.

Нужен Python 3.10+ и pygame-ce:

```powershell
python -m pip install pygame-ce
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь | направление взгляда и фонаря |
| Shift | бег (тратит выносливость) |
| F | включить/выключить фонарь |
| Esc | пауза |
| R | заново после смерти/победы |

## Цель

1. Найти карту уровня 1 в **Зоне содержания** (север).
2. Открыть дверь в **Офисы** и забрать карту уровня 2.
3. Через **Лабораторию** попасть в **Реактор**, найти карту уровня 3.
4. Вернуться в **Столовую**, открыть шлюз и добежать до выхода.

## Механики

- **SCP-173** активируется, когда вы берёте первую карту. Он замирает,
  пока вы на него смотрите (в конусе зрения фонаря и без стен между вами),
  и быстро идёт к вам, стоит отвести взгляд или моргнуть.
- **Моргание** происходит автоматически каждые 5–8 секунд. В этот момент
  экран темнеет, а 173 получает ускорение — не подпускайте его близко.
- **Фонарь** тратит батарею, но без него угол обзора и дальность намного
  меньше. Батарея медленно восстанавливается, когда фонарь выключен.
- **Двери** открываются автоматически при подходе, если есть карта
  нужного уровня.
- **Бег** расходует выносливость, но позволяет оторваться от 173.
