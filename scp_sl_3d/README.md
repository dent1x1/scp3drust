# SCP: Secret Laboratory — 3D

Фанатский 3D-прототип на Rust + Bevy 0.15.

## Играть без разработки

Папка `dist/scp_sl_3d` — готовый exe + `ИГРАТЬ.bat`. Нужны только Windows
10/11 x64 и видеокарта с Vulkan.

## Собрать из исходников

```
cargo run              # отладка
cargo build --release  # релиз
```

Нужен Rust stable `x86_64-pc-windows-gnu` + MinGW GCC (WinLibs) или MSVC
Build Tools. Путь к линкеру может быть прописан в `.cargo/config.toml`.

## Управление

WASD — движение · мышь — взгляд · Shift — бег · F — фонарь ·
Esc — пауза · Enter — начать · R — заново

## Цель

Собрать карты доступа 1–3 уровня и добраться до шлюза.
SCP-173 замирает, пока вы на него смотрите; моргнёте — он ударит.

Подробности о совместной разработке — в `../COLLAB.md`.
